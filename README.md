Arcaea Custom Course Mode Generator (v6.10.8)

Open the project through your terminal and run the code.

1) Play
Select which "phases" would you like to play; higher phases means you will encounter more difficult songs.
- The plus after a difficulty number means it's actual difficulty is .7-.9 (a 10+ means it's either a 10.7, 10.8, or 10.9).
- 'Random' option picks 4 random songs with no difficulty restrictions.
- After selecting a phase number, the program will pick 4 songs from the roster inside the .csv file, and good luck practicing the songs!

2) About
Gives a small description on what the project is about.

3) Exit
Terminates the program.
